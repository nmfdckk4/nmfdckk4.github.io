理論推導與公式解析 靜電學專題

鏡像法原理 (Method of Images)

利用球外虛擬鏡像電荷 $q'$ 取代導體內壁感應電荷的效應，使腔壁 $r = a$ 處滿足等電位邊界條件：

$$c' = \frac{a^2}{c}, \quad q' = -Q\frac{a}{c}$$

當 $c \to 0$ (電荷位於球心) 時，$c' \to \infty$，$q' \to -\infty$，鏡像電場退化為均勻常數電位 $-Q/a$。

內壁感應電荷面密度 $\sigma(\theta)$

依據高斯定理與導體表面場強關係 $E_n = \sigma / \varepsilon_0$，內壁分佈為：

$$\sigma(\theta) = -\frac{Q}{4\pi a} \frac{a^2 - c^2}{\left(a^2 + c^2 - 2ac\cos\theta\right)^{3/2}}$$

總感應電荷積分恆為 $\oint \sigma \, dA = -Q$。電荷越偏離球心，$\theta=0^\circ$ 側的負電荷聚集越劇烈。

點電荷受到的淨吸引力 $\vec{F}$

電荷 $+Q$ 受到內壁非均勻感應電荷的淨吸引力，等價於真實電荷與虛擬鏡像電荷間的庫侖吸引力：

$$\vec{F} = \frac{k Q |q'|}{(c' - c)^2} \hat{r} = \frac{k Q^2 a c}{\left(a^2 - c^2\right)^2} \hat{r}$$

方向恆指向距離最近的腔壁。當 $c=0$ 時受力為零（對稱平衡）；當 $c \to a$ 時吸引力急劇發散。

靜電屏蔽與外表面特性

  • 導體殼內部 ($a < r < b$)：靜電平衡下 $\vec{E} = 0$，電位恆為常數。
  • 中性孤立球殼：外壁聚集 $+Q$ 且均勻分佈，外部電場 $E = \frac{kQ}{r^2}$ 呈完美中心對稱放射狀，無論 $+Q$ 在腔內如何偏心移動，外部電場均完全不變！
  • 接地球殼：外表面電荷經接地流入大地，$Q_{\text{out}} = 0$，外部完全無電場 ($E_{\text{ext}} = 0$)。

外電荷電場 $\vec{E}_Q$ (穿透外場)

點電荷 $+Q$ 在空間任意位置 $\vec{r}$ 產生的庫侖電場為：

$$\vec{E}_Q(\vec{r}) = \frac{k Q (\vec{r} - \vec{d})}{|\vec{r} - \vec{d}|^3}$$

此放射狀電場穿透整片空間，包含導體球內部區域（由近端指向遠端）。

感應電荷電場 $\vec{E}_{\text{ind}}$ (球內反向)

在外場影響下，導體表面電子重新分佈：近側聚集負感應電荷、遠側聚集正感應電荷。在導體球內部，感應電荷產生由遠端指向近端的反向電場：

$$\vec{E}_{\text{ind}}(\vec{r}) = -\vec{E}_Q(\vec{r}) \quad (\forall r < b)$$

方向精確朝向外電荷 $+Q$，大小處處與外場 $\vec{E}_Q$ 嚴格相等！

靜電平衡內部電場完全抵銷

依據疊加原理，導體內部的總合電場恆為零：

$$\vec{E}_{\text{total}}(\vec{r}) = \vec{E}_Q(\vec{r}) + \vec{E}_{\text{ind}}(\vec{r}) \equiv 0 \quad (\forall r < b)$$

若內部電場不為零，自由電子將持續受力漂移，直到感應場與外場完美抵銷。這就是「導體內部電場為零」的微觀機理！

球外區域之鏡像法解

在球體外部 ($r \ge b$)，感應電荷的電場等價於虛擬鏡像電荷：

  • 偏心鏡像：位於 $d' = \frac{b^2}{d}$ 處，電量 $q' = -Q\frac{b}{d}$。
  • 球心鏡像 (中性孤立球)：位於原點 $(0,0)$，電量 $q_0 = +Q\frac{b}{d}$。
  • 受力：外電荷受到導體感應電荷的淨吸引力，方向指向球心。

感應電荷會影響外部電場嗎？（常見概念解析）

答案是：必然會！ 依據庫侖定律，表面感應電荷所建立的電場同樣會穿透到導體外部全空間：

  • 內部剛好抵銷：導體內部自由電子持續移動，直到感應場在內部處處與外場反向相等（$\vec{E}_Q + \vec{E}_{\text{ind}} = 0$）。
  • 外部無法抵銷，導致電力線彎曲：在導體外部，兩者幾何方位不同，向量疊加後形成向導體彎曲的合電力線並垂直入射表面。
  • 吸引力的物理鐵證：外電荷 $+Q$ 受到的庫侖吸引力 $\vec{F}$，正是表面感應電荷在外部空間施加的電場力！若感應電荷不影響外部，$+Q$ 將完全感受不到導體的存在。
